# Cosmere Automated Actions
A module to add automations to the CosmereRPG system for FoundryVTT

## Features
Currently this only adds a compendium pack with items that have automations built in via events and macros. You muse replace the items on your character sheet with the items in the compendium

Current automated items include:
- Recover
- Breathe Stormlight

And a custom item
-Pocket Sand
